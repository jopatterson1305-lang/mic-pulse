# MIC Pulse

MIC Pulse — East African business, technology, finance and opportunity intelligence platform.

## Stack

- Next.js + React + TypeScript
- Tailwind CSS
- GSAP / ScrollTrigger
- Lenis
- Three.js / React Three Fiber for selective 3D
- Lucide React
